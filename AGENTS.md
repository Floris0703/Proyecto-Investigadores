# Agentes y responsabilidades — TESCo Investigadores

Repositorio: `Floris0703/Proyecto-Investigadores`. Rama principal: `master`.

- **github**: revisión, sincronización, seguridad de cambios, Pull Requests y merge autorizado.
- **frontend**: Landing, Alumnos, HTML/CSS, Bootstrap y JavaScript.
- **backend**: PHP, SQLSRV, consultas parametrizadas, sesiones y acceso.
- **base_datos**: SQL Server, T-SQL, integridad, diccionario de datos y migraciones.

## Reglas
1. Antes de trabajar, consultar el HEAD de la rama y las modificaciones ajenas.
2. Revisar `.coordinacion/config.json`, `.coordinacion/README.md`, tareas y `docs/CONTRATOS_INTEGRACION.md`.
3. No cambiar `master` directamente. Proponer rama y PR para revisión.
4. Nunca exponer secretos, datos personales, volcados SQL o información privada en el repositorio público.
5. No ejecutar SQL destructivo, push o merges sin autorización explícita.
6. Al terminar: registrar archivos, pruebas, riesgos, dependencias y un resumen para el coordinador.
7. La notificación GitHub Actions **no equivale** a activar un chat de ChatGPT.
